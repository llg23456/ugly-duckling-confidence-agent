# 小丑鸭 Confidence Agent

一款面向缺乏自信用户的温情 AI 成长陪伴 Android 应用。当前版本已打通多模态会话、分层记忆、支持圈与求助反馈、日周月回望、本机演示社区、成长小片、桌面组件和可信数据导出主链路。

## 当前完成内容

### Android 与交互

- **首页**：小丑鸭陪伴区、对话气泡、相关记忆、低压力行动建议、图片入口和语音电话入口；发消息栏始终固定在底部导航栏上方。回复采用结构化对话决策，直接问题优先回答，召回证据只展示模型实际使用的内容；多条证据可轻量展开。
- **成长**：日/周/月结构化回望、独立本周报告、关键成长线，以及可按主题选择 3～7 天素材、按日生成摘要并组合多图的成长小片。
- **社区**：宋体、扁平卡片和探头小鸭组成的本机演示信息流，可搜索、点赞、进入帖子详情查看模拟讨论和系统分享；点赞后图标与数量变红。用户可以把已保存的文字、语音转写、照片或视频发布为本机持久化帖子；成长小片生成后可直接进入社区发布页撰写配文，视频在帖子详情中可播放。
- **记录**：文字记录编辑区、语音/图片入口、保存区域和最近记录。
- **我的**：陪伴方式、画像记忆中心、隐私权限、JSON/ZIP 数据导出、求助资源等设置入口。
- 多套透明背景的小丑鸭动作素材，避免所有页面使用同一姿态。
- 冷启动展示“小鸭迈向新芽”封面，系统闪屏与桌面图标同步使用米白小鸭视觉。
- 品牌标题保留站酷快乐体，长正文与按钮使用系统字体提高可读性；艺术字体依照 SIL Open Font License 1.1 随应用分发。

当前首页文字、图片和语音对话已接入后端。记录页支持文字、相机/相册、照片批注和本地保存；“说一句”会同时保存原始 WAV 与转写文字，最近记录可查看全文、放大照片或再次播放语音。已保存记录的文字、转写和照片说明会同步为成长事件，原声与照片只保留在本机。首次画像、可实时更新的画像记忆中心和三个桌面小组件均已接通。

社区是比赛演示所需的“本机真实发布＋内置模拟内容”，不是联网公开社区。新发布的帖子从 0 点赞、0 评论、0 分享开始，不自动附加模拟讨论；五条内置动态分别使用与正文匹配且互不重复的演示评论。帖子详情保留点赞、评论和分享，不提供收藏。导入语音时只使用转写文字；照片和视频发布时复制独立媒体副本，删除原始记录或成长小片不会破坏已发布帖子。自己的帖子、媒体和自定义头像会进入数据导出和“删除全部数据”，模拟帖子不会冒充真实用户数据。

成长页基于真实事件生成日、周、月结构化回望，节点可返回原始对话、反馈或本地记录。周页不再重复铺开七天摘要，只保留故事封面、关键成长线和本周变化；周报告用每日心情折线图和本周心情扇形统计代替“七天的一句话”，忐忑使用琥珀色、低落使用紫色以保持清楚区分。情绪优先读取事件字段，没有明确情绪时再依据当天回望文字做本地归类。

报告底部进入成长小片。素材选择页只展示按时间排列的原始内容以及已有的照片、语音和中敏感提醒，不提前显示 AI 摘要；用户可通过推荐主题和补充搜索选择 3～7 天的素材，同一天允许选择多条。点击生成后，服务端才将同一天已选内容整理为可编辑的“当日故事摘要”。手机准备竖屏画面、字幕、原声与配音，电脑端调用 FFmpeg 合成为 H.264/AAC MP4；服务端按片段情绪在“忐忑/低落”和“轻松/平稳”两首舒缓纯音乐之间切换，连续同类片段保持同一首连续播放。预览后可以保存、系统分享，或直接进入社区发布页撰写配文。

桌面展示默认关闭。开启后可在“我的—隐私与权限”分别为“今日成长”和“本月足迹”主动选择一条已保存的文字、语音或照片记录：文字和语音只显示简短文字，照片显示经过缩放的照片与配文；未选择时回退为经过敏感过滤的成长事件。记忆中心展示“起步—尝试—成长”小鸭形象、行为关键词与变化时间线；完整画像和更新历史按需展开，关键词与阶段均可查看原始记录依据。

数据导出提供两种方式：“仅导出 JSON”生成体积较小、适合查看和演示的 v2 文档；“导出完整 ZIP”额外包含本机照片、原声、社区图片、社区头像、聊天图片和成长小片。JSON 先按本地日期列出每天的聊天及逐条置信度状态，再列出合并去重后的主动记录和自己的社区帖子，最后按成长与记忆、支持信息、主动关心和视频脚本分区保存。

成长页采用“本地缓存先显示、后台按需刷新”：打开 App 时不再预加载未进入的成长页；日、周、月每次切换只请求一次聚合接口，周内七天和月内各周不再由手机逐项请求。成功结果在本机缓存五分钟，聊天、生活记录或求助反馈产生新内容后自动标记失效；断网时仍优先保留上次可用回望。服务端只允许本周期主报告调用一次 AI 润色，子摘要使用可追溯模板或已有缓存。即使本周报告直接命中本地缓存，App 也会在后台补齐成长小片需要的原始事件以及照片、原声的本地记录映射，避免出现“报告有内容，小片却没有可选素材”。

首页现已支持有来源的主动关心：同类受阻、紧张或低落在不同日期重复出现，或用户明确希望之后追问时，后端建立一次待问候，并立即弹出一次“小鸭记住了”的确认消息；下次打开 App 后，小鸭才在聊天流中正式询问近况。用户可继续聊、说明好转或暂不回答，系统会按选择进入冷却期。该功能不诊断疾病，也不会增加固定的风险按钮；明确危险表达仍由当前对话立即给出安全引导。

首页会话使用 Room 本地缓存，并与后端 SQLite 历史同步；同一设备的文字、图片和语音消息共享会话，服务端在回复时读取最近 12 条消息。首页只展示手机当地日期为今天的对话；跨天后旧文字、语音转写和图片不删除，仍保留在数据导出和历史回望来源中。App 启动或跨过零点时会补生成尚未归档的历史日回望。设备 ID 在本机持久保存，多设备账号同步尚未实现。

每轮回复保存后会独立执行 `memory-v2` 提取：保留一个兼容成长页的合并成长事件，同时从最近上下文中识别最多五个原子记忆点，区分身份、偏好、目标、持续处境、支持关系和真实经历。计划、否定、已完成行为、明确纠正和“不记录/忘掉刚才”分别处理；证据必须来自用户消息，助手建议不能变成用户已完成事实。重复事实合并来源和出现次数，明确纠正替代旧记忆，普通冲突或敏感信息等待确认。未配置模型、证据不成立或两次结构校验均失败时不会写入。

召回继续使用关键词与向量混合检索，但改为相关度、类型、重要度和时间的单一加权分数，并进行近重复过滤和总文本预算限制。短句或“那个、后来、还是”等指代会补充最近两条用户消息；只使用低敏感、已确认的活动记忆。`chat-v2` 要求模型返回实际使用的记忆或记录 ID，因此首页不会再把“仅被检索到、但回复没有引用”的内容显示成相关记忆。

### 后端与 AI 接口

- FastAPI 分层目录与配置管理。
- 健康检查、聊天、成长事件提取、一起向前支持建议、周期回顾接口。
- 聊天接口已支持真实百炼模型，未主动启用或调用失败时自动返回模拟数据。
- 对话主链路会输出并校验 `reply / intent / strategy / topic / used_memory_ids`；正常聊天只进行一次同步模型调用，格式异常时最多修复一次。明确危险表达由程序规则立即返回安全引导，并跳过普通召回、成长事件和延迟问候。
- 图片接口支持 JPEG、PNG、WebP；语音页录制 16 kHz 单声道 WAV，由模型转写并回复。
- 回复默认由 `qwen3-tts-flash` 朗读，可在“我的—调整陪伴方式”选择 `Serena` 温柔女声、`Ethan` 温暖男声或系统声，并控制自动朗读和提示音；云端 TTS 失败自动回退到系统声。
- 成长小片按 3～7 个日期生成每日摘要；多图日期可能展开为多个连续画面，因此渲染接口最多接收 40 个画面。电脑端使用 FFmpeg 合成；云端流式 WAV 会先按实际字节数修正 RIFF/data 长度，避免 Android 将十余秒配音误判为数小时。
- `一起向前`只生成联系谁、如何开口等建议，不替用户自动发送消息。
- 首次认识采用自然语音介绍和缺项追问，画像及最多 36 次有变化的快照保存在 Android 本地；敏感字段允许“不愿透露”。记忆中心可根据近期用户发言和主动保存记录更新画像；变化保留前后对照并可点开详情。两个不同日期的真实尝试进入“尝试”，四个不同日期的尝试加上求助、调整或生活照顾的依据进入“成长”。依据置信度至少 0.75，排除演示记录、高敏感、未来计划及明确否定的行为；阶段没有打卡或分数要求，停止记录不会降级。
- 三个 Glance 桌面小组件分别提供今日成长、本月足迹和快速记录，快捷按钮可进入记录页对应模式。今日与本月组件仅在“我的—隐私与权限”明确开启后展示内容，可分别选择主动记录；照片会先缩小以避免桌面组件传输过大，关闭权限时清除展示缓存。

接口文档和启动方法见 [server/README.md](server/README.md)，模型与 API 决策见 [API与技术方案总结.md](API与技术方案总结.md)，当前状态、主干任务和具体实现顺序见 [开发交接_当前状态与待实现.md](开发交接_当前状态与待实现.md)。

## Android 运行

1. 使用 Android Studio 打开本目录。
2. 等待 Gradle Sync 完成。
3. 通过 Android Studio 的设备列表安装运行，或把调试 APK 安装到手机。
4. 手机与运行后端的电脑连接同一个 Wi-Fi；首次安装已带当前测试地址，网络变化后可在 App 内重新检测。

建议使用绿色三角形 **Run app**，不要长期使用 Debug 运行。若真机在 Android Studio 打开时出现触摸卡住，可在 `Settings → Tools → Device Mirroring` 关闭自动设备镜像，并确认 Debug 面板没有停在断点。

## 后端启动、检查与关闭

以下命令均在 PowerShell 中执行。

### 1. 检查 8000 端口是否已有后端

```powershell
$listener = Get-NetTCPConnection -LocalPort 8000 -State Listen -ErrorAction SilentlyContinue | Select-Object -First 1
if ($listener) {
    Get-CimInstance Win32_Process -Filter "ProcessId = $($listener.OwningProcess)" |
        Select-Object ProcessId, Name, CommandLine
} else {
    Write-Output "8000 端口空闲，可以启动后端"
}
```

### 2. 启动后端

```powershell
cd .\server
python -m uvicorn app.main:app --host 0.0.0.0 --port 8000
```

该终端需要保持运行。另开一个终端检查服务：

```powershell
Invoke-RestMethod http://127.0.0.1:8000/health |
    Select-Object status, mock, ai_configured, chat_model
```

真实模型正常时应看到 `status=ok`、`mock=False`、`ai_configured=True`。

成长小片还要求电脑已安装 FFmpeg，并确保 `ffmpeg`、`ffprobe` 可从命令行访问：

```powershell
where.exe ffmpeg
ffmpeg -version
where.exe ffprobe
```

若 FFmpeg 未加入 `PATH`，可在 `server/.env` 中设置完整路径，例如：

```dotenv
FFMPEG_PATH=C:\ffmpeg\bin\ffmpeg.exe
```

### 3. 通过同一 Wi-Fi 连接手机与后端

推荐先启动后端，然后在 App 中进入：

```text
我的 → 帮助与求助资源 → 一键检测当前 Wi-Fi
```

App 会扫描手机当前 Wi-Fi 网段的 `8000` 端口，只有 `/health` 返回小丑鸭服务标识时才保存，并立即让聊天、回望、记忆、支持圈、视频脚本和桌面组件使用新地址。检测不到时，可以在同一弹窗手动输入地址并点击“检测并保存输入地址”。

需要手动确认电脑地址时，执行：

```powershell
ipconfig
```

找到正在使用的 **无线局域网适配器 WLAN**，记录其中的 IPv4 地址，例如：

```text
10.113.21.33
```

不要使用 VMware、WSL、蓝牙或已断开网卡的地址。运行时地址会保存在手机本地，不需要每次修改 Gradle 或重新安装。只有制作新的默认安装包时，才需要在 `gradle.properties` 设置：

```properties
apiBaseUrl=http://10.124.233.33:8000
```

将示例 IP 换成电脑当前的 WLAN IPv4。项目在开发测试阶段已经允许访问任意 HTTP 地址，因此不需要再修改 `network_security_config.xml`。

最后在手机浏览器中访问：

```text
http://10.113.21.33:8000/health
```

能看到 `status: ok` 后，App 才具备通过 Wi-Fi 访问后端的网络条件。若手机浏览器打不开，请检查 Windows 防火墙、手机和电脑是否确实连接同一 Wi-Fi，以及当前网络是否启用了设备隔离。电脑重新联网后 IPv4 可能变化，届时在 App 内重新执行一键检测即可。

### 4. 安全关闭占用 8000 的后端

先检查占用进程，只有命令行中包含 `uvicorn app.main:app` 时才结束：

```powershell
$listener = Get-NetTCPConnection -LocalPort 8000 -State Listen -ErrorAction SilentlyContinue | Select-Object -First 1
if (-not $listener) {
    Write-Output "8000 端口没有正在运行的后端"
} else {
    $backendProcess = Get-CimInstance Win32_Process -Filter "ProcessId = $($listener.OwningProcess)"
    if ($backendProcess.CommandLine -match "uvicorn\s+app\.main:app") {
        Stop-Process -Id $backendProcess.ProcessId
        Write-Output "后端已关闭"
    } else {
        Write-Warning "8000 端口由其他程序占用，未自动关闭：$($backendProcess.CommandLine)"
    }
}
```

如果后端正在前台终端运行，也可以直接在该终端按 `Ctrl+C` 关闭。

也可以直接安装调试包：

```text
app/build/outputs/apk/debug/app-debug.apk
```

## 手机验收清单

1. **启动**：应用能正常启动，无闪退、白屏或明显卡顿。
2. **底部导航**：首页、成长、社区、记录、我的五个页面可来回切换，选中状态正确；已有桌面组件仍进入成长页或记录页，不因社区插入第三项而错位。
   - 社区重点检查：搜索框与发布按钮保持扁平横向布局；点赞后心形和数字变红，再点恢复；点帖子或评论进入无底部导航的详情页；详情只显示点赞、评论、分享，不出现收藏。自己的帖子与内置演示帖均可点击头像或配图，从拍照、相册更换本机展示素材；自己的自定义头像重启后仍保留。
3. **首页**：早上、中午、下午、晚上和深夜显示对应问候；小丑鸭和卡片没有被裁切；长文本不溢出；输入框可以输入中文。空会话和有会话时，发消息栏都应固定在底部导航栏正上方。隔天打开时首页只显示今日对话，昨日内容仍可从成长日回望、来源跳转和数据导出中找到。
4. **成长**：日页默认昨天且不重复罗列事件；周页不再显示周一至周日长摘要卡，只保留成长线，底部“本周报告”进入独立报告页。周报告应显示周一至周日的心情折线和本周心情扇形统计，无记录日期留空；忐忑与低落必须分别显示为琥珀色和紫色；五个主线框严格按“开始与行动—遇到的困难—应对与支持—真实的变化—仍在继续”推进。
5. **成长小片**：进入后确认“本周共有 N 条可选素材”，选择 3～7 天并生成可编辑摘要。合成后检查完整旁白、最多五秒原声和背景音乐同时存在且互不遮盖；忐忑/低落片段应使用 `Chillax`，轻松/平稳片段应使用 `Look At The Bright Side`，连续同类片段中音乐不能重新起播，情绪组切换时应平滑换曲。再检查全屏预览、保存副本、系统分享，以及“去社区写配文并发布”能带着视频打开社区发布页。发布后列表显示视频封面，详情页可以播放，整片仍不得超过 5 分钟。
6. **记录**：编辑区可以输入多行文字；最近记录能完整展示。
7. **我的**：所有设置项均可看到，滚动到底部无重叠。
8. **语音音色**：在“我的—调整陪伴方式”切换女声、男声和系统声；关闭自动朗读后可在语音页用播放按钮手动朗读。
9. **首次认识**：首次启动可语音介绍、修改转写、继续回答追问或跳过；完成/跳过后重启不应重复出现。
10. **真实记录**：分别测试写一句、说一句原声＋转写、相机、相册、照片批注、保存与草稿；点击最近记录应能看全文、看大图或播放原声。
11. **记忆中心**：初次打开可先看到本机缓存，联网后核对来源；默认按“现在—形成过程—画像详情与历史”的顺序展示阶段形象、最多四个关键词和变化时间线，点开关键词或阶段可看整理后的来源卡片，并返回聊天、求助反馈或原始生活记录。点击主图只切换阶段查看，不显示显眼的“换图/删除”控件；完整画像可以编辑并保存，历史按需展开。画像刷新后可以对照变化，重复刷新不增加相同快照；“重新认识”保留成长记录，断网保留上次内容。
12. **桌面组件**：添加三个“小丑鸭”组件，确认写/说/拍分别进入正确模式；在“我的—隐私与权限”检查默认关闭、开启后预览和关闭时撤销。开启后分别选一条文字记录和带照片、配文的照片记录，确认两个成长展示组件会刷新为所选内容；选语音记录时只能看到转写文字，不出现原声。
13. **适配**：重点观察状态栏、底部系统导航栏、圆角屏和不同字体大小下是否遮挡内容。
14. **启动封面**：冷启动应先显示小鸭迈向新芽的封面约 1.8 秒，然后进入首次画像或首页。
15. **演示数据**：Debug 版本从“我的—数据导出—测试数据准备”生成固定的 2026-09-07 至 09-13 考研主故事，并自动打开对应周；也可生成最近四周扩展故事。主线包括确定目标、学习受挫、父母支持、向目标院校师兄师姐和学院老师请教、运动与户外休息、调整方法以及继续准备；没有预设录取结果。演示记录不会计入个人阶段和关键词；清除演示数据后重新核对剩余来源，真实记录不应被删除。
16. **补记素材**：在成长日详情的“这一天留下的记录”底部点击补充按钮，添加文字、照片或语音；保存后记录日期应属于所选那天，而不是今天。
17. **主动关心**：先清除或使用新设备数据；只留一条“紧张/卡住/低落”记录时不应触发，跨两个日期留下同类内容后重启 App 应看到小鸭问候。分别检查“想聊聊”“比昨天好一点”“现在不想说”；暂不回答后不应立即再次出现。
    - 第二条同类记录同步完成，或发送“明天再问问我”等明确请求后，应先弹出一次“小鸭记住了”；弹窗本身不等于正式问候，正式问候仍在下次打开 App 时出现。
18. **后端连接**：进入“我的—帮助与求助资源”，确认显示当前地址；更换 Wi-Fi 后点击一键检测能找到电脑并保存，返回首页后可以直接刷新会话，不必重新安装 App。
19. **成长页性能**：首次进入成长页允许出现一次加载；同一日/周/月再次进入应立即显示缓存。切换周、月时每个页签只等待一次请求；保存新聊天或记录后，旧内容应先显示并提示后台更新，而不是整页空白。后端关闭后，已经打开过的周期仍应能显示上次缓存。
20. **单条记录删除**：打开最近记录并删除，确认本机照片或原声消失；再看成长页、画像更新和后续聊天召回，相关事件、派生记忆与旧回望不再出现。可在断网时删除一次，恢复网络并重新进入记录页后确认服务端也完成清理。
21. **数据导出**：选择“仅导出 JSON”应得到体积较小、可直接查看的 v2 文档；选择“导出完整 ZIP”时，压缩包除同一结构的 `data.json` 外，还应包含 `media` 目录中的照片、原声、聊天图片和成长小片。JSON 顶部先按日期列出 `daily_chats`，每条消息均有 `confidence_status`；用户消息若提取到事实会同时显示 `confidence`、0.75 阈值、五项 `score_components`、`value_score`、敏感度和最终 `memory_decision`，助手回复及未提取事实的消息以 `null` 和状态说明明确区分。全部聊天之后再列出 `saved_records`，其余长期记忆、回望、支持信息和视频脚本分区保存。旧数据在本次更新前未保存五项分数，因此其 `score_components` 可能为 `null`。后端关闭时仍应导出本机记录，并在 `export_info` 中标明服务端不可用。
22. **删除全部数据**：建议先导出，再点击删除全部数据并二次确认；完成后应回到首次认识，聊天、记录、成长、记忆中心和桌面组件不再显示旧内容。

### 导师建议改进验收

- **阅读层次**：日回望先显示一句话和最多三条来源；周成长线先显示三个节点；月回望先显示三个短栏目。展开能读完整内容，点开节点能追溯来源。在小屏幕及放大字体下检查文字换行、滚动和底部按钮。
- **支持圈**：增加 `senior`（师兄师姐），与已有类型兼容，无需数据库结构迁移。对话进入 `seek_support` 后会在情绪回应下方自动显示求助卡；只要支持圈中有用户保存的联系人，就优先从中按适合场景和关系类型选择，不再优先生成泛称对象。消息始终由用户自行决定是否发送。
- **成长依据**：两条同日记录不能解锁尝试阶段；四天只有学习尝试、没有求助/调整/生活照顾时仍停留在尝试阶段。成绩、录取、打算和否定句不能直接触发变化。删除记录后同步清理依赖快照；删除全部数据清空本地画像及历史，重新认识保留既有经历。
- **导出**：JSON/ZIP 的 `memory_and_growth.local_profile_history` 包含当前画像、快照及阶段来源，离线也可以导出本机历史；其余 v2 字段兼容原有格式。
- **成长小片**：无照片时显示学习、请教、运动或户外的透明主题插画；FFmpeg 服务播放完整旁白和最多五秒原声，再按每段情绪混入两首授权舒缓背景音乐并拒绝超过五分钟的素材。生成后可携带视频直接进入社区发布页。
- **视觉素材**：当前三阶段使用 `app/src/main/res/drawable-nodpi/duck_growth_start_v3.png`、`duck_growth_try_v3.png`、`duck_growth_open_v3.png`，三张图都带局部场景，并通过姿态和神态表现“起步—尝试—成长”。四张故事场景素材为同目录的 `duck_story_study.png`、`duck_story_guidance.png`、`duck_story_exercise.png`、`duck_story_outdoors.png`；社区另使用 `duck_community_header.png` 和 `duck_community_avatar.png`。素材使用内置 image_gen 生成并参考既有小鸭风格，早期提示词保存在 [素材提示词清单](docs/advisor-art-prompts.json)。

2026-10-03 真机验证：REDMI K80 Ultra（Android 16）通过 10 项不同的设备测试，其中包含 5 项界面流程；离线原文、三阶段、师兄师姐、JSON 画像历史、全部删除及实际视频播放均通过。另完成约 295 dp 窄屏复查。后端 40 项、Android JVM 11 项测试通过，普通 Debug 与隔离测试包构建成功。详见 [真机验收记录](docs/advisor-device-acceptance.md)，包含测试隔离方式、复现命令、修复项及验证范围。
23. **混合记忆召回**：保持云端 AI 开启，先建立一条长期记忆，再换用语义相近但不重复原关键词的说法聊天，观察是否出现相关记忆；关闭云端 AI 后，相同关键词召回应继续工作。再发送一个无关问题，首页不应显示这条记忆；只有回复实际使用的证据才显示来源卡。
24. **多记忆点与纠正**：发送“我叫小李，现在大三，目标院校是北师大，我难受时希望你先听我说”，检查身份、目标和陪伴偏好被拆分；随后发送“不是北师大，是另一所学校”，检查旧目标标记为已替代，新目标成为活动记忆。计划和否定句不能解锁成长阶段。
25. **记忆控制与安全**：发送“这件事不要记”时不应新增记忆；在一条新记忆后发送“忘掉刚才那件事”，该记忆应从列表和召回中移除。明确危险表达应立即显示安全引导，不显示旧记忆，也不创建普通成长事件。

目前首页多模态、首次画像、记录、画像记忆中心、支持圈、求助建议和反馈、分层日周月回望、主动关心、陪伴音色、成长小片、桌面组件及可信数据闭环均已接入。所有主动保存的生活记录直接进入可检索记录库；聊天内容才经过置信度和长期价值判断进入长期记忆。新照片会生成客观画面描述用于检索，单条记录删除会同步清理派生内容；“我的—数据导出”可单独导出 JSON、导出完整 ZIP 或删除全部数据；召回使用关键词与向量混合检索。导师建议涉及的真机流程与窄屏布局已验收；真实云端画像、云端配音、麦克风与相机仍需专项联调。

## 已确认的正式技术方案

- Android：Kotlin、Jetpack Compose、Material 3，最低 Android 8.0（API 26）。
- 后端：Python、FastAPI、Pydantic Settings。
- 云端模型：阿里云百炼 DashScope，由后端持有 `DASHSCOPE_API_KEY`。
- 多模态聊天：`qwen3.8-omni-flash`。
- 结构化提取与总结：`qwen3.7-flash`。
- 语音对话与转写：第一版使用 `qwen3.8-omni-flash`直接理解 WAV；后续需要专业长录音转写时切换 `paraformer-v2`。
- 向量嵌入：`qwen3.7-text-embedding-flash`，768 维。
- 语音播报：`qwen3-tts-flash`（`Serena` / `Ethan`），Android 系统 TTS 作为离线/失败回退。
- 视频合成：Android 按 3～7 天生成 540×960 PNG 画面与本地媒体素材，FastAPI 使用 FFmpeg 输出 H.264/AAC MP4；多图日期按每四张一页扩展，单片最多 40 个画面、总时长最多 5 分钟。

API Key 不写入 Android APK，也不提交到 GitHub；只放在服务端 `.env` 中。
