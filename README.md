# 鸭力Go

Android 成长陪伴 App，客户端使用 Kotlin / Jetpack Compose，服务端使用 FastAPI、SQLite 和百炼模型。

当前 Android 云测版固定连接 **https://api.yaligo-growth.top**。香港服务器提供后端，电脑只用于开发和运维；手机正常使用时电脑可以关机。

## 目录

- `app/`：Android 代码、界面、资源与测试。
- `server/`：后端代码、运行配置模板、接口测试及本地开发环境。
- `deploy/cloud-test/`：Docker、HTTPS、备份、邀请管理与接口检查工具。
- `gradle/`、Gradle 启动文件：Android 构建所需。
- `licenses/`：随应用资源分发的许可证。

PPT、设计原稿、比赛材料和历史方案放在外层 `../docs/`，不属于本 Git 仓库。2026-11-15 整理的旧方案、旧验收结果和生成物放在 `../docs/archive/2026-11-15-cleanup/`，其中 `cleanup-manifest.json` 记录原路径和归档路径。历史材料不代表当前验证结果。

`.env`、数据库、SDK 路径、IDE/Gradle 缓存等本机状态保留在本机，并由 `.gitignore` 排除。Docker 构建仅接收后端实际需要的源码和配置模板所对应的构建文件，不携带本机数据或密钥。

## 手机运行

1. 在 Android Studio 打开本目录，完成 Gradle Sync。
2. 选择 `app` / `debug`，用 Run 安装并启动。
3. App 名称为“鸭力Go·云测”，包名 `com.testconnection.confidence_agent.cloudtest`。
4. 首次使用输入独立邀请码。已有云测版正常覆盖升级时保留数据和授权；不要为了升级而卸载或清除应用数据。

云测版无需与电脑连接同一 Wi-Fi，也不需要本机后端。新增的 `localDebug` 是独立本地测试版，使用不同包名和数据，不需要云测邀请码。修改后端需由队友发布服务器后才会影响云测版。

## 服务器使用与接口检查

服务器结构、SSH 连接、邀请管理、Git 提交和后端发布步骤见 [云测运维说明](deploy/cloud-test/README.md)。

当前分工：本机修改并验证后推送源码，队友负责部署服务器；本机无需配置 SSH。手机固定使用云端，后端改动在队友发布后才会对手机生效。

在项目根目录运行以下命令，可检查公网健康、认证边界及文档端点封闭情况。它不调用模型，不读写任何用户数据：

```powershell
.\deploy\cloud-test\check-public.ps1
```

`/health` 的 `ai_configured=true`、`mock=false` 只说明服务配置已启用真实 AI；实际某次聊天是否调用成功，需要查看该次响应。接口就绪不等于全部手机功能验收通过。

## 本地后端开发

本机已有 `server/.venv` 时，在项目根目录执行：

```powershell
cd .\server
.\.venv\Scripts\python.exe -m app.local_dev
```

默认使用模拟 AI、模拟短信及独立数据库 `server/.local-data/wellbeing.db`。测试真实百炼理解时加 `--live-ai`，读取本机 `.env` 的已有模型凭据；加此参数不会开启真实短信。只有在本地 App 的联系人编辑页授权“紧急时通知此人”后，该设备才使用真实短信。保持终端打开，访问 `http://127.0.0.1:8000/health`；结束时按 `Ctrl+C`。

手机本地测试：Android Studio 的 Build Variants 中将 app 的 Active Build Variant 选为 `localDebug`，再点击 Run。安装后名称为“鸭力Go · 本地”，包名以 `.local` 结尾；只有云测版安装在手机上时，新功能和本地连接入口不会出现。

本地版“我的”页顶部提供“本地测试 · 后端连接”，显示当前地址及检测结果：

- 同一热点 / Wi-Fi：后端启动命令加 `--host 0.0.0.0`，即 `.\.venv\Scripts\python.exe -m app.local_dev --live-ai --host 0.0.0.0 --port 8000`。在手机点“一键检测局域网”，或手动填写电脑的局域网 IP（例如 `http://10.105.172.33:8000`）并检测保存。切换热点后 IP 可能变化。此模式只用于可信局域网中的本地测试，不做公网端口映射。
- USB：保留默认环回监听，执行 `adb reverse tcp:8000 tcp:8000`，再在“手动地址 / USB 连接设置”中点“连接 USB 本地后端”。模拟器也可使用 reverse。重连 USB 后可能需要重新执行命令。

本地版默认地址为 `http://127.0.0.1:8000`，该地址在手机上只有配置 USB reverse 后才指向电脑。本地 `localDebug` 允许开发用 HTTP；云测 debug/release 保持 HTTPS + 邀请认证，不显示服务器切换入口。

## 压力与安全功能（第一版）

- 首页每日心情 + 压力自评；压力温度计和 7 / 30 / 365 天折线。自评默认占 70%，AI 估计占 30%，缺失来源不作为 0。提醒线和权重可微调，旧日期保留当时版本。
- 当天明确表达本人当前伤害意图时，当日参考值至少为 90，页面注明“含当日强烈困扰表达”。这是产品显示规则，不是模型估计、医学阈值或危险概率。普通后续聊天不抹去当日记录，删除来源后重新计算，次日独立记录；短信条件独立运行。今日旧缓存自动升级。
- 对话、语音转写、记录和照片的用户说明统一进行规则 + 结构化模型筛查，校验原文证据并处理否定、引用、历史语境。明确的本人当前行动计划可快速处理；其他表达按最新原话和上下文判断，需要通知时再做一次不带初次结论的语义复核。两次判断不一致或复核不可用时先澄清，不自动外发；这不是两个独立模型或临床评估。
- 明确的本人当前轻生想法无需带“今晚/打算”等固定词也可在语义复核通过后通知。“累死了、学得快不想活了”等高压抱怨只进入压力与支持对话，不单凭关键词跨过通知条件；语义不清先澄清。模型离线时非紧迫表达只给支持提示，不把无法判断当成确认安全。
- 支持圈先由 AI 判断本轮需要学习安排、专业解答还是倾诉陪伴，再按用户保存的用途匹配；作业负担不会仅因压力高而改派情绪联系人，明确指定的人优先。推荐卡的联系人不决定自动短信收件人，后者只能由用户事先设置。
- 添加或编辑支持圈联系人时必填手机号，可在同页开启紧急提醒；本地 `localDebug` 用手机短信发送。只从已提前授权、适合情绪支持的联系人中匹配一人，不会选仅用于专业问题的老师。人工核对号码不等于运营商归属验证。
- `python -m app.workers.notifications --local` 可独立恢复和处理本地模拟队列；加 `--once` 只执行一次。本地服务重启也恢复未完成任务。模拟状态不代表真实送达，真实接入还需号码核验、供应商签名模板和回执处理。
- 生活影响自查为自编问题，不是标准化心理量表。专业支持可通过支持圈手动联系；组织者配置 `COUNSELING_URL=https://...` 后，自查页显示机构预约入口。未配置时明确提示尚未开通，不虚构咨询师或预约结果。
- 安全检测不能保证覆盖所有谐音、隐喻或危险情境。压力分数和紧急通知条件独立，不能当作临床诊断。

新增接口均位于 `/api/v1/wellbeing`（today、history、check-in、preferences、contacts、notifications、self-check），继承设备认证与所有权检查。数据导出、清空及原消息/记录删除会同步处理新增数据。

### 联系人自动短信

1. 启动本地后端并在 Android Studio Run `localDebug`。手机连接同一可信热点或 USB reverse。
2. 测试机需要可发送短信的 SIM 卡和余额；在系统设置里选择默认短信卡，不使用“每次询问”。实现使用 Android [SmsManager](https://developer.android.com/reference/android/telephony/SmsManager)，首次需要授予 `SEND_SMS` 权限；只有本地构建声明此权限。
3. 在“支持圈 → 添加/编辑联系人”或“压力温度 → 可信联系人 → 添加/编辑”填写必填手机号和支持场景。阅读包含时间、类型及必要原话摘要的新说明，允许短信权限并确认接收人同意后保存。旧演示联系人需编辑确认一次，不会静默升级为可披露原话。
4. 保持 App 在前台与后端连通，使用双方约定的合成测试语句。明确的当前行动计划可直接触发；“我已经不想活了”等当前个人想法在真实模型结合语境并复核通过后也会触发。高压抱怨、引用、否定、转述他人和历史记录不应只因关键词触发。测试多条短信请注意10分钟冷却。
5. 到“通知记录”刷新查看。`已发出` 是系统发送回执，`运营商已报告送达` 需要所有分段的成功送达报告，均不等于对方已读；请由接收人实际核对。演示结束在“自动安全提醒”关闭。

新版短信带“鸭力Go安全提醒”字样，说明北京时间、触发来源（对话/记录）、风险表达类型，以及最多40字的相关原文片段；区分“相关想法，需要关心陪伴”和“出现近期行动信号”，不附完整聊天、图片或诊断，不把意图表述为行为已经发生。通知记录可展开查看相同内容。同一联系人 10 分钟内最多自动通知一次，任务 2 分钟过期。号码变更、撤销、删除来源会阻止尚未交给系统的任务；已交给系统的短信无法撤回。进程退出、请求丢失或回执缺失时不自动补发，显示结果待确认。手机关闭、后台限制、无余额、无信号、权限撤销或本地后端中断都可能阻止演示发送。这不是后台持续运行的云短信方案。

`support-people` 的 `contact_version=2` 在同一事务保存联系人、必填手机和新版授权；真实发送仅在开发环境且 `NOTIFICATION_MODE=mock`、未启用云认证时开放，每位联系人返回独立令牌（列表不返回令牌）。旧 `device-sms/setup` 仅保留旧版兼容。`claim` 原子领取、`authorize` 发送前复核且只成功一次、`receipt` 记录结果。令牌仅保存摘要，Android 凭据与发送日志排除系统备份；测试不会调用真实运营商发送。

### 行动推荐与聊天成长素材

- 聊天的“一起想下一步”卡片内可左右滑动：第一页保留联系人、求助话术与反馈，第二页直接列出三条行动建议，跟随最新问题变化。底部两个圆点标示当前页，不另设跳转或聊天按钮。
- 成长日页默认今天，日回望只显示一句主要发生了什么（通常25—50字），不展开分析或建议；原始记录仍完整列出。周页默认本周。回望同时读取全部用户聊天、已保存记录及求助反馈；未成为成长事件的表达也可作为原始材料，不写入成就或长期记忆。计划、感受和实际行动分别表述。
- 新图片消息在原图理解的同一次模型调用中保存客观图片观察（标记待核实），用于每日压缩汇总。旧图片没有事后猜测识别内容；已在本机保存的聊天原图可在原始记录查看，也可进入小片照片页。
- 成长 → 周 → 周报告 → 成长小片：选择3—7天素材、预览和编辑后生成；沿用现有高敏感素材过滤。原图保存在当前手机私有目录，不提供跨设备原图恢复，卸载或清除应用数据后可能丢失。
- `/reviews/materials` 提供回望/小片的只读素材视图，保留真实来源；负ID编码原始来源，不新增虚构成长事件。生成小片重新核对设备所有权，删除原始来源后相关脚本失效。

新增图标来自 [Lucide](https://github.com/lucide-icons/lucide)，许可证随应用放在 `app/src/main/assets/licenses/lucide.txt`。小鸭沙漏插画使用项目原小鸭作风格参考，通过内置图片生成工具生成。

依赖、接口、FFmpeg 和模型环境配置见 [后端说明](server/README.md)。本地 API 文档为 `http://127.0.0.1:8000/docs`；公网不开放 Swagger。

## 当前功能范围

应用包括多模态对话、记录、分层记忆、主动关心、压力趋势、日周月回望、成长小片、支持圈、数据导出和桌面组件。社区为本机持久化演示社区，不是联网公开社区；多设备账号同步尚未实现。

另以旧 `main`（`750418f`）创建合成数据库，再用新源码执行升级：原聊天、联系人、邀请码和授权记录保留，SQLite 完整性检查通过；生产模式下未授权返回 401、跨设备返回 403，已有凭据可继续使用，压力自评、联系人保存、建议和日回望接口正常，手机短信仍受生产禁用限制。此验证只操作合成数据，没有连接生产数据库或发送真实短信。

本机未安装 Docker，且本地 Python 依赖与部署锁文件存在版本差异，因此尚未验证 Linux 镜像构建和镜像内测试。队友部署时必须按[交接与发布步骤](deploy/cloud-test/README.md)完成这些检查，并进行真实云端与手机联调。此前真实模型合成样例可用于回归参考，不代表真实人群中的检测准确率；历史记忆提取和并发耗时问题也不作已解决结论。

建议按此顺序验收：

1. 在Android Studio Run `localDebug`，保留手机上的应用数据；本地后端端口仍为8000。
2. 编辑原有母亲联系人，核对手机号、情绪支持场景和新版原话摘要说明，再保存；老师保持专业用途。
3. 发一段文字及一张反馈截图，在“一起想下一步”内滑到第二页，检查3条建议是否对应刚才的内容；白色圆点应跟随当前页变化，滑回第一页后编辑的话术应保留。
4. 切到“成长 → 日”，检查今天的汇总、原始来源和图片缩略图；点来源可回到聊天。旧图片仍保留本机原图，但没有新版本的自动图片观察时不会补猜内容。
5. 累积或补充3—7天素材后，在“成长 → 周 → 周报告 → 成长小片”选择素材、预览和生成。
6. 在已告知的测试联系人配合下检验自动短信，核对接收人、时间和原话；普通提问、否定和引用不得只因危险词自动发送。
