# Bundled audio

Growth videos select music for every scene and keep the same track playing across
adjacent scenes in the same mood group:

- `bgm_reflective_chillax.m4a`: **Chillax** by Francisco Alvear, used for tense
  or low scenes. Source: <https://assets.mixkit.co/music/655/655.mp3>. The first
  10 seconds were removed because the source begins almost silently.
- `bgm_bright_side.m4a`: **Look At The Bright Side** by Michael Ramir C., used
  for relaxed, steady, or bright scenes. Source:
  <https://assets.mixkit.co/music/964/964.mp3>.

Both tracks are provided under the Mixkit Stock Music Free License:
<https://mixkit.co/license/#musicFree>. They are bundled only for mixing into
generated videos; do not redistribute either audio file as a standalone track.
The renderer loudness-normalizes both tracks, then applies a `0.174` mix gain,
which is approximately 10 dB below the previous `0.55` background gain.

`gentle_growth_bgm.m4a` is the previous project-original fallback generated by
`server/scripts/generate_original_bgm.py`; the current renderer no longer selects
it.
